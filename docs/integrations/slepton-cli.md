# SleptON! in Concierge

Concierge can connect to the separately installed [SleptON! CLI 1.1.0](https://github.com/bhengubv/thegeeknetworkapps/releases/tag/slepton-cli-v1.1.0). The connection is optional. It discovers the CLI's live manifest and accepts only eight reviewed read operations: search, public apps, app details, nearby events with explicit coordinates, owned apps, account details, releases, and update checks. A changed command contract exposes no tools.

Install the release `.nupkg` in a local feed with `dotnet tool install SleptOn.CLI --version 1.1.0 --add-source PATH_TO_FEED --tool-path PATH_TO_TOOLS`. Put the installed `slepton` executable on `PATH`, or set `SLEPTON_CLI_PATH` to its absolute path before starting Concierge. Open **Tools and features → SleptON! → Connect**. No CLI command runs during Concierge startup.

Every call asks before contacting SleptON!. Concierge constructs an argument array without a shell, enforces a 40-second deadline, checks the JSON envelope, and labels returned content as untrusted. Public calls receive no account bearer. On Desktop, the two account reads use the signed-in TheGeekNetwork account token only in the child process environment. The Web host exposes public reads only until it has a per-person secure token vault. Android, iOS, and Mac Catalyst do not expose this subprocess integration; their local CLI runtime has not been verified. Publishing and `--submit` are excluded, and any `SLEPTON_PUBLISH_API_KEY` inherited by Concierge is removed from the child environment.

The 1.1.0 release package SHA-256 was checked against its published checksum: `c9ff9677db34bc11a62260e0aa3f7d3599b0e21a7ca9ba90b9659b6a5a040c37`. The bundled fixture smoke test passed on Windows, and the installed CLI returned a valid live public app catalogue envelope. Concierge's adapter tests cover changed commands, approval, token isolation, argument arrays, and invalid location. Live authenticated reads and a Concierge UI test with a signed-in account remain unverified.

For Apple packaging, the [Circle MAUI Apple Build 1.0.0](https://github.com/bhengubv/thegeeknetworkapps/releases/tag/circle-maui-apple-build-v1.0.0) package is referenced only by Concierge's iOS and Mac Catalyst targets. Its vendored NuGet file matches the published SHA-256 `3034b14691445cadef5efe1e4b73d307a24f8bb8b39e97231decb528a291060b`. Both Apple target restores passed on Windows. An Apple compiler, IPA, code signature, and device run have not yet been verified for Concierge.
