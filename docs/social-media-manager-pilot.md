# Social Media Manager pilot

Concierge remains a general assistant. A Project may opt into a focused vocation profile. The first profile is Social Media Manager; the profile is stored with the Project and survives reopening it. Other conversations keep their existing skills and tools.

## Try it

1. Open **Projects**, choose the **Social Media Manager** starter under Work, and create the Project.
2. Review or edit the five campaign steps: brief, content plan, assets, approval, measurement.
3. Select **Work with Concierge**. This creates a conversation linked to the Project.
4. Ask for a campaign brief or calendar. The bundled marketing skill is attached to turns in that Project, and the Project's goal and steps are supplied as context.
5. Check the tool chips before requesting research, images, media export, or a reminder. A chip reports whether the tool is offered in this app; provider readiness and permissions are checked when used.

The marketing skill requires approval before publishing or spending money. This pilot has no connected social publisher or analytics account, so publication and performance measurement still need a person or a configured integration. It does not silently post, buy ads, or claim an asset was created when a provider is unavailable.

## Why this shape

The Project owns the outcome, editable workflow, conversations, and artifacts. The vocation profile supplies a relevant skill and highlights tools already registered in the app. Circle AI remains the engine; the profile does not select a model. The profile is an additive Project context, so ordinary chats remain general purpose.

The linked GitHub forks are research references, not dependencies in this pilot. No upstream code or assets were copied. Any future integration needs a separate technical and licence review.

## Current limits

- Tool chips indicate registration, not that a provider, account, or network connection is ready.
- Publishing and analytics ingestion are not implemented here.
- The pilot is not an embedded IDE, music studio, or general vocation marketplace. Its profile and project binding provide the seam for those later modes.
