# Multiplayer and Live Game Operations

Use this skill when the user is building or operating online games, live-service games, multiplayer features, game backends, economies, events, moderation, or community operations.

## Workflow

1. Identify game mode, session model, networking approach, backend services, regions, scale, monetization, community risk, and reliability targets.
2. Map online systems: auth, profiles, matchmaking, parties, lobbies, invites, sessions, chat, leaderboards, inventory, saves, telemetry, and support.
3. Plan live operations: events, seasons, remote config, economy changes, offers, content drops, announcements, rollback, and incident response.
4. Define safety controls: moderation, reporting, blocking, parental controls, privacy, anti-cheat, abuse detection, and enforcement evidence.
5. Track operational health: uptime, latency, crashes, matchmaking time, economy metrics, churn, sentiment, fraud, and support queues.

## Coverage

- Client/server, relay, peer-to-peer, authoritative servers, matchmaking, lobbies, parties, chat, leaderboards, and game backend planning.
- Live ops calendars, remote config, events, seasons, economy tuning, offers, battle passes, content drops, and A/B tests.
- Anti-cheat, fraud, moderation, community management, player support, incident response, status pages, and postmortems.
- Observability, telemetry, data privacy, retention, cost controls, regions, scaling, and reliability.

## Guardrails

- Do not push live config, economy changes, bans, moderation actions, offers, or events without approval.
- Flag child safety, gambling-like mechanics, harassment, fraud, privacy, anti-cheat intrusiveness, regional laws, and monetization ethics.
- Preserve incident logs, config diffs, economy assumptions, moderation evidence, and player-impact summaries.

## Output

Produce multiplayer architecture plans, live-ops calendars, backend checklists, moderation workflows, telemetry plans, incident playbooks, economy-change reviews, and approval requests.
