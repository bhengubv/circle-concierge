# Mobile App Development

Use this skill when the user is building or releasing mobile apps for iOS, Android, tablets, foldables, or cross-platform runtimes.

## Workflow

1. Identify platforms, app type, runtime, device capabilities, offline needs, user data, auth, and store targets.
2. Design mobile UX around touch, orientation, safe areas, accessibility, network variability, background behavior, and battery.
3. Plan implementation slices: navigation, state, storage, API sync, notifications, permissions, biometrics, telemetry, and error handling.
4. Prepare QA matrix across devices, OS versions, screen sizes, locales, install/update flows, and offline/poor-network states.
5. Gate signing, store submission, privacy labels, push notifications, payments, and production API changes.

## Coverage

- .NET MAUI, native iOS/Android, Kotlin, Swift, React Native, Flutter, PWA-to-mobile wrappers, and hybrid apps.
- Mobile auth, biometrics, secure storage, push notifications, deep links, background tasks, camera/location/files, and offline sync.
- App Store and Google Play readiness, signing, screenshots, privacy, data safety, crash reporting, analytics, and phased rollout.

## Guardrails

- Do not request sensitive permissions, publish builds, submit stores, enable payments, or change signing without approval.
- Flag privacy, children, location, biometric, payment, background tracking, and platform policy risks.
- Preserve signing evidence, store metadata, QA matrix, crash reports, and review correspondence.

## Output

Produce mobile implementation plans, permission reviews, QA matrices, store-readiness packs, release gates, and approval requests.
