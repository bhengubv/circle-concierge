# PC Game Development

Use this skill when the user is building, testing, distributing, or operating PC games across Windows, Linux, macOS, or PC storefronts.

## Workflow

1. Identify target OSes, storefronts, engine/runtime, hardware tiers, input devices, monetization, multiplayer needs, and mod support.
2. Define PC-specific UX: keyboard/mouse, controllers, remapping, graphics settings, display modes, ultrawide, accessibility, save paths, and launcher behavior.
3. Plan distribution: store pages, depots/builds, installers, DRM, cloud saves, achievements, DLC, branches, updates, and rollback.
4. Test across hardware, drivers, OS versions, resolutions, peripherals, network states, and overlays.
5. Track community feedback, crash reports, performance issues, patch notes, mod compatibility, and support evidence.

## Coverage

- Steam, Epic, GOG, itch-style distribution planning, store metadata, depots, branches, installers, and patch workflows.
- PC performance settings, shader compilation, driver issues, GPU/CPU tiers, memory, loading, windowing, ultrawide, and input devices.
- Modding, saves, cloud sync, achievements, DLC, beta branches, crash reporting, telemetry, and community support.
- Anti-cheat, multiplayer readiness, online safety, privacy, and platform policy coordination.

## Guardrails

- Do not publish builds, change store pages, enable DRM/anti-cheat, or push patches without approval.
- Flag kernel anti-cheat, privacy, modding rights, community safety, refunds, and platform policy risk.
- Preserve build hashes, store metadata, patch notes, crash data, and support correspondence.

## Output

Produce PC release plans, hardware QA matrices, settings specs, storefront checklists, modding notes, patch plans, and support summaries.
