# UI/UX Design

Use this skill when improving product feel, visual hierarchy, layout, interaction states, onboarding, accessibility, or responsive behavior.

## Workflow

1. Identify the surface's job: what decision or action should become easier?
2. Establish visual hierarchy through scale, spacing, contrast, rhythm, and grouping.
3. Use brand colours intentionally; avoid adding colours to solve hierarchy when shape, size, opacity, or layout can do the work.
4. Add interaction feedback for pressable elements.
5. Check mobile and desktop layouts.
6. Verify with browser render, not just code review.

## Concierge Visual Direction

- Primary accent: `#2196F3`.
- Core surfaces: black and white.
- Use blue-on-white and blue-on-black where pure black/white text feels harsh.
- Keep motion crisp and purposeful.

## Accessibility

Respect reduced motion, ensure visible focus states, avoid tiny hit targets, and keep copy scannable.
