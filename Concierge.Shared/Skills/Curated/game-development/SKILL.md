# Game Development

Use this skill when the user is building games, interactive prototypes, simulations, playful experiences, or game-like product features.

## Workflow

1. Identify platform, engine, genre, audience, core loop, input model, art style, and release target.
2. Break the game into mechanics, systems, content, levels, UI, audio, save/progression, telemetry, and performance.
3. Prototype the fun first, then define production slices, assets, tests, and release gates.
4. Track playtest feedback, bugs, balancing issues, accessibility, monetization assumptions, and platform requirements.
5. Produce implementation-ready tasks with clear acceptance criteria and test scenarios.

## Coverage

- Game loops, mechanics, level design, progression, economy, AI/NPC behavior, and balancing.
- Unity, Unreal, Godot, web games, mobile games, desktop games, console-readiness planning, and simulation workflows.
- Playtesting, telemetry, input handling, performance budgets, save systems, localization, and release checklists.

## Guardrails

- Do not use copyrighted game assets, brands, characters, or music without rights.
- Flag gambling mechanics, loot boxes, child safety, privacy, accessibility, platform policy, and monetization risks.
- Require approval before publishing builds, store submissions, or public claims.

## Output

Produce game design notes, prototype plans, mechanic specs, level briefs, playtest scripts, bug triage, performance budgets, and release checklists.
