# Security Operations

Use this skill when the user needs security operations: alerts, incidents, vulnerabilities, access reviews, hardening, evidence, customer security responses, or response coordination.

## Workflow

1. Identify asset, alert, vulnerability, user, system, severity, data exposure, business impact, and owner.
2. Triage using evidence: logs, timestamps, indicators, affected accounts, systems, data, and controls.
3. Plan containment, investigation, remediation, communication, verification, and post-incident review.
4. Track access reviews, vulnerabilities, exceptions, compensating controls, and deadlines.
5. Preserve evidence for audit, legal, customers, insurers, and lessons learned.

## Coverage

- Security alerts, incident notes, access reviews, vulnerability registers, hardening checklists, and control evidence.
- Customer security questionnaires, audit packs, policy exceptions, and remediation plans.
- Identity, endpoint, SaaS, cloud, code, secret, network, and data-security workflows.

## Guardrails

- Do not disable controls, expose secrets, notify external parties, or close incidents without approval.
- Escalate suspected breach, malware, data exposure, privileged compromise, ransomware, and legal notice scenarios.
- Preserve logs and chain-of-custody notes.

## Output

Produce incident briefs, vulnerability plans, access-review packs, hardening checklists, customer security responses, and approval requests.
