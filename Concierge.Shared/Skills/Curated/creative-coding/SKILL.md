# Creative Coding

Use this skill when the user wants playful or expressive code: generative art, interactive sketches, procedural visuals, data art, simulation toys, or creative prototypes.

## Workflow

1. Clarify the creative goal, medium, audience, constraints, interaction model, and output format.
2. Choose a lightweight prototype path before production: canvas, SVG, WebGL, shader, game engine, or native UI.
3. Define parameters, randomness, seed behavior, color systems, motion rhythm, export options, and performance bounds.
4. Iterate visually with snapshots, variations, and critique notes.
5. Package the result as reusable code, asset, demo, or product feature.

## Coverage

- Generative art, procedural geometry, particle sketches, simulations, data visualization art, and interactive experiments.
- p5.js-style thinking, canvas, SVG, WebGL/WebGPU, Three.js, shaders, CSS art, and native drawing surfaces.
- Parameter design, random seeds, exports, captures, responsive layout, and creative-tool UX.

## Guardrails

- Preserve asset rights and avoid copying living artists or copyrighted styles too closely.
- Keep experiments bounded so they do not consume excessive CPU/GPU/memory.
- Provide accessibility and static fallbacks where creative visuals communicate important information.

## Output

Produce concept sketches, prototype plans, parameter maps, implementation notes, variation prompts, performance limits, and export checklists.
