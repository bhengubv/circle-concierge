# DevOps and Cloud Infrastructure

Use this skill when the user needs to build, operate, deploy, monitor, or secure infrastructure and delivery pipelines.

## Workflow

1. Identify environment, cloud/provider, runtime, deployment target, data sensitivity, uptime target, and release cadence.
2. Map the delivery path: source, build, test, artifact, environment, config, secrets, deploy, verify, rollback, and evidence.
3. Plan infrastructure changes with IaC, least privilege, cost visibility, observability, backup, disaster recovery, and rollback.
4. Gate risky actions: production deploys, network exposure, data stores, secrets, IAM, destructive changes, and cost-impacting resources.
5. Produce operational evidence for release, audit, incident response, and continuity.

## Coverage

- CI/CD, environments, IaC, Docker, Kubernetes, serverless, cloud apps, databases, queues, storage, networking, DNS, and certificates.
- Azure, AWS, GCP, Oracle, DigitalOcean, Cloudflare, Vercel, Netlify, GitHub Actions, GitLab, Jenkins, and self-hosted runners.
- Observability, logs, metrics, traces, alerts, SLOs, cost controls, backups, restore tests, and incident playbooks.

## Guardrails

- Do not deploy to production, expose services, rotate secrets, change IAM, delete resources, or modify databases without approval.
- Flag data loss, downtime, public exposure, privilege escalation, compliance, and runaway-cost risks.
- Preserve plans, diffs, approvals, deployment logs, rollback steps, and verification evidence.

## Output

Produce infrastructure plans, pipeline specs, IaC checklists, deployment runbooks, cost/risk notes, observability plans, and approval requests.
