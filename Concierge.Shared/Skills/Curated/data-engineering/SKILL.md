# Data Engineering

Use this skill when the user needs reliable data pipelines, ingestion, transformation, warehousing, analytics foundations, or data operations.

## Workflow

1. Identify source systems, data owners, consumers, freshness requirements, volume, sensitivity, and quality expectations.
2. Map ingestion, transformation, validation, storage, lineage, orchestration, access, and retention.
3. Design pipelines with idempotency, schema evolution, replay, monitoring, backfills, and failure handling.
4. Gate sensitive data movement, production schema changes, retention changes, and external sharing.
5. Produce evidence for analytics, audit, privacy, and operational support.

## Coverage

- ETL/ELT, batch, streaming, APIs, files, CDC, queues, warehouses, lakes, lakehouses, marts, and semantic layers.
- SQL, dbt-style transformations, orchestration, data quality checks, lineage, cataloging, privacy controls, and access reviews.
- Power BI/Looker/Tableau/Metabase readiness, analytics events, product telemetry, and reporting foundations.

## Guardrails

- Do not move sensitive data, expose datasets, delete tables, or change retention without approval.
- Flag PII, financial data, health data, credentials, cross-border transfer, lineage gaps, and unverified metrics.
- Preserve schemas, transformation logic, run logs, validation results, and data-quality evidence.

## Output

Produce pipeline designs, data contracts, quality checks, lineage notes, backfill plans, warehouse models, and approval requests.
