# Console Game Development

Use this skill when the user is building, porting, testing, certifying, or releasing games for console platforms.

## Workflow

1. Identify target platforms, access status, dev kit constraints, engine/runtime, controller model, performance target, age rating, and release path.
2. Map platform requirements: certification rules, technical requirement checklists, save data, achievements/trophies, parental controls, network state, user switching, suspend/resume, and entitlement handling.
3. Plan console UX: controller-first navigation, couch co-op, split screen, accessibility, safe areas, localization, platform overlays, and input remapping.
4. Prepare release evidence: build version, package metadata, store assets, test matrix, known issues, platform notes, patch plan, and rollback.
5. Track certification failures, waivers, platform feedback, fixes, resubmissions, and approval history.

## Coverage

- Console platform readiness, dev kit planning, certification evidence, TRC/XR-style checks, and submission workflow.
- Controller UX, local multiplayer, achievements/trophies, cloud saves, suspend/resume, profiles, entitlements, and platform services.
- Performance budgets, memory, loading, storage, crash handling, telemetry, localization, accessibility, and age ratings.
- Patch rules, DLC, updates, store packaging, review notes, compliance screenshots, and release gates.

## Guardrails

- Do not expose confidential platform documentation, SDK material, or dev kit details.
- Do not submit builds, change store metadata, publish patches, or request waivers without explicit approval.
- Flag platform NDA, certification, age rating, online safety, user data, and monetization risks.
- Preserve evidence for every certification issue, waiver, and platform response.

## Output

Produce console-readiness plans, controller UX specs, certification checklists, QA matrices, store submission packs, patch plans, and approval requests.
