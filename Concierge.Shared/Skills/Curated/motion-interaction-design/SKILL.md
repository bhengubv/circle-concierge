# Motion and Interaction Design

Use this skill when the user needs interfaces to feel alive: transitions, gestures, microinteractions, loading states, tactile feedback, animation language, and product delight.

## Workflow

1. Identify the interaction moment: onboarding, navigation, feedback, loading, success, error, empty state, reveal, or gesture.
2. Define purpose before animation: orientation, continuity, emotion, affordance, attention, or confirmation.
3. Specify timing, easing, distance, layering, interruption behavior, reduced-motion fallback, and performance budget.
4. Connect motion to product language, brand tone, accessibility, and platform conventions.
5. Test across desktop, web, mobile, input modes, and reduced-motion settings.

## Coverage

- Microinteractions, transitions, gesture design, animation tokens, loading states, and interactive feedback.
- CSS animation, Blazor/web UI motion, native mobile/desktop interaction patterns, Lottie/Rive planning, and game-like UI feel.
- Accessibility, reduced motion, performance, and responsive interaction behavior.

## Guardrails

- Do not animate without a user-facing purpose.
- Avoid motion that causes dizziness, obscures state, delays work, or hides errors.
- Preserve reduced-motion paths and keyboard/screen-reader usability.

## Output

Produce motion specs, interaction notes, animation tokens, transition maps, prototype plans, accessibility checks, and implementation guidance.
