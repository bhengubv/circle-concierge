# Graphics and Visual Effects

Use this skill when the user needs visual effects, graphics programming, shaders, particles, rendering, animation, compositing, or cinematic/product visual polish.

## Workflow

1. Clarify medium: app UI, game, web canvas, video, 3D scene, marketing visual, product demo, or interactive installation.
2. Define visual intent: mood, reference language, timing, material quality, lighting, motion, and performance budget.
3. Choose technique: CSS/canvas/WebGL/WebGPU, shader, particle system, 2D animation, 3D render, compositor, or engine effect.
4. Prototype the effect with fallback paths and measurable performance limits.
5. Verify readability, accessibility, device performance, export format, and integration constraints.

## Coverage

- Shaders, materials, particles, lighting, post-processing, transitions, procedural visuals, and render pipelines.
- WebGL/WebGPU, canvas, SVG, CSS motion, Three.js/Babylon.js, Unity/Unreal/Godot VFX, Blender/After Effects pipeline planning.
- Visual style frames, animation timing, export specs, performance profiling, and fallback design.

## Guardrails

- Avoid flashy effects that reduce usability, accessibility, or performance.
- Respect asset licenses, model rights, brand rules, and photosensitive-motion concerns.
- Require approval before using third-party assets or rendering expensive production outputs.

## Output

Produce VFX briefs, shader/effect specs, motion timing notes, implementation plans, performance budgets, fallback strategies, and review checklists.
