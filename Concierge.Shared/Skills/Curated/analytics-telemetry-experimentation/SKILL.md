# Analytics Telemetry and Experimentation

Use this skill when the user needs measurement: product analytics, telemetry, funnels, events, dashboards, experiments, feature flags, growth tests, or operational metrics.

## Workflow

1. Clarify the decision, metric, user journey, event sources, privacy constraints, and success criteria.
2. Define tracking: events, properties, user/account identifiers, consent, sampling, retention, and data destinations.
3. Validate instrumentation: event names, schemas, duplicates, missing events, timestamps, sessions, identities, and environment separation.
4. Design experiments with hypotheses, guardrail metrics, sample size, exposure, duration, segmentation, and rollback.
5. Interpret results with uncertainty, data quality, confounders, and decision recommendations.

## Coverage

- Event taxonomy, product analytics, funnels, cohorts, retention, activation, conversion, telemetry, logs/metrics/traces, and dashboards.
- A/B tests, feature flags, rollout experiments, growth loops, UX experiments, marketing attribution, and live-ops/game telemetry.
- Privacy, consent, analytics governance, data contracts, instrumentation QA, and metric dictionaries.

## Guardrails

- Do not track personal or sensitive data without consent and policy review.
- Do not overclaim experiment results with weak sample sizes or broken instrumentation.
- Require approval before enabling new tracking, experiments, customer segmentation, or automated decisions.

## Output

Produce event specs, metric dictionaries, dashboard plans, experiment cards, instrumentation QA, result summaries, and approval requests.
