# Audio Music and Sound Design

Use this skill when the user needs product sound, game audio, music direction, sonic branding, voice workflows, or audio implementation planning.

## Workflow

1. Identify context: UI feedback, game audio, video, podcast, brand, accessibility cue, notification, voice, or ambient soundscape.
2. Define sonic intent: emotion, tempo, texture, loudness, duration, repetition, platform, and environment.
3. Plan assets, triggers, states, mixing, fallbacks, localization, accessibility, and licensing.
4. Verify volume, interruption behavior, user control, device output, latency, and platform rules.
5. Package audio notes for implementation, review, and release evidence.

## Coverage

- UI sounds, notification sound, game SFX, ambient loops, music direction, voiceover workflows, and sonic branding.
- Audio asset lists, state maps, implementation triggers, mixing notes, compression/export specs, and platform constraints.
- Licensing, attribution, accessibility cues, mute controls, and user preferences.

## Guardrails

- Do not use copyrighted music, voices, samples, or celebrity likenesses without rights.
- Avoid intrusive, repetitive, inaccessible, or unconfigurable audio.
- Require approval before publishing or shipping audio assets.

## Output

Produce sound briefs, asset lists, trigger maps, music direction notes, licensing checklists, implementation specs, and review plans.
